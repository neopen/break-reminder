Privacy Policy

隐私政策

生效日期：2026-11-21 · 适用于 Breakly（别坐了）桌面应用 v1.1.0 及后续版本

感谢使用 Breakly（别坐了）。本政策说明应用在你使用过程中如何处理信息。核心原则很简单： 你的设置和打卡数据只保存在本机，我们不会收集或上传。

01我们处理的信息

应用仅在本机处理以下数据，用于提供提醒与统计功能：

  • 提醒设置：提醒间隔、休息时长、工作时段、免打扰时段、提醒方式、声音开关等；
  • 活动统计：每日与每周的活动次数、连续打卡天数；
  • 系统偏好：开机启动、自启动提醒、系统锁屏等开关状态。

我们不收集姓名、账号、手机号、位置、通讯录、剪贴板、设备标识、使用行为分析或任何可识别个人身份的信息，也不包含广告或第三方统计 SDK。

02数据存储与删除

上述数据保存在你电脑的本地应用数据目录（config.json 与 stats.json），不会同步到云端。卸载应用或手动清除应用数据后，相关记录即被删除。

03网络访问

应用仅在以下场景访问网络，且不会附带你的设置或打卡数据：

  • 检查更新：访问 GitHub Releases 获取版本信息；
  • 在线反馈、关于我们、在线工具：通过系统默认浏览器打开对应网页；
  • 发送邮件：调用系统默认邮件客户端，邮件内容由你自行决定。

04系统权限

  • 通知：仅在桌面通知模式下请求，用于弹出休息提醒；
  • 开机启动：可在「系统与统计」中随时关闭；
  • 全局键盘拦截：仅在锁屏休息窗口期间启用，用于防止跳过强制休息；
  • 系统锁屏：仅在你开启「系统锁屏」后，于休息结束时调用系统锁屏。

所有权限均只在对应功能启用时使用。

05第三方服务

应用可能通过 GitHub 提供版本更新与问题反馈，通过系统通知服务展示提醒，通过系统邮件客户端发送反馈。这些服务由相应提供方运营，适用其各自的隐私政策。

06数据安全

数据保存在本机，应用不会建立云端账户。请妥善保护你的系统账户与设备安全；共享电脑上的本地数据可能被其他使用者看到。

07未成年人

本应用不面向未成年人单独收集个人信息，也不会主动收集任何个人身份信息。

08政策更新

隐私政策可能随功能更新而调整。重大变更会通过应用版本说明或在应用内提示。继续使用即表示你接受更新后的政策。

09联系我们

如对本政策有任何疑问，可通过邮件 helpenx@gmail.com 或应用底部「功能反馈」与我们联系。
